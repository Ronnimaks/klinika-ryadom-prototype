# Правила этого сайта (рабочее название «Клиника 24», бренд уточняется)

- Логотип и любые надписи из букв и цифр: один шрифт, одна высота, цифры на одной линии с буквами (владелец, 11.11.2026). Поэтому логотип пишется ЗАГЛАВНЫМИ.
- Шрифты Geologica + Onest, цвета графит/сине-зелёный + янтарный акцент утверждены 11.11.2026.
- Сплошной белый текст без акцентов не оставлять: в каждом блоке ключевые слова фирменным цветом.
- Картинки сохранять оригиналом из генератора, без снимков экрана и пережатия (прошлые были мутными из-за этого).
- Экраны без пустоты: тёмное фото фоном или объединение двух блоков.
- Правка - в _исходники, затем python собрать_сайт.py.
- Первый экран - только для пациента. Планы клиники (какие направления откроются) - отдельным блоком ниже, для показа заказчику (владелец, 11.11.2026).
- Кнопок минимум. На первом экране одна оранжевая «Записаться». Телефон всегда в шапке. «Написать» - круглая кнопка чата справа внизу, прячется при прокрутке. Закреплённых кнопок внизу экрана нет.
- Двойное касание не приближает страницу.
- Анимации от прокрутки идут за центром экрана, а не убегают вперёд.
